# Troubleshooting

| Symptom                                       | Cause                                               | Fix                                                                                                                                            |
| --------------------------------------------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Client shows the server as failed / no tools  | Wrong executable or path                            | Run the configured command in a terminal. Use absolute paths (`which node`). Run `npm run build` if `dist/` is missing.                        |
| `MCP error -32602 ... output schema`          | Client built against an old server build            | `npm run build`, then restart the server in the client.                                                                                        |
| `png` / `pdf` listed in `export_errors`       | Chromium not installed, or timeout                  | `npx playwright install chromium`; raise `D3MCP_BROWSER_TIMEOUT_MS`.                                                                           |
| `FIELD_NOT_FOUND`                             | Encoding references a missing column                | The error hint lists the available fields. Fix `options.encoding`.                                                                             |
| `INCOMPATIBLE_DATA: Log scale ...`            | Zero or negative values on a log axis               | Use `symlog` (refinement does this automatically).                                                                                             |
| `LIMIT_EXCEEDED`                              | Dataset over the configured limits                  | Aggregate or sample, or raise `D3MCP_MAX_ROWS` / `D3MCP_MAX_INPUT_BYTES`.                                                                      |
| `INVALID_INPUT: Invalid artifact_id`          | ID contains `/`, `.` or other disallowed characters | Use the ID returned by the tool.                                                                                                               |
| `ARTIFACT_NOT_FOUND`                          | Expired (TTL) or different artifact directory       | Re-render. Check that `D3MCP_ARTIFACT_DIR` matches between runs.                                                                               |
| HTML opens but is blank                       | Browser blocks `file://` scripts (rare)             | Open in Chrome, Edge, Firefox or Safari. The page needs no network.                                                                            |
| Garbled stdout / protocol errors              | Something wrote to stdout                           | The server logs only to stderr. Don't wrap it in scripts that `echo`.                                                                          |
| Slow responses for large graphs               | A large force layout keeps a render worker busy     | Other requests still proceed. Reduce nodes, lower `options.iterations` (default ≈ 300 ticks, bounded 100–300) or raise `D3MCP_RENDER_WORKERS`. |
| `LIMIT_EXCEEDED: Rendering ... exceeded N ms` | Render hit `D3MCP_RENDER_TIMEOUT_MS`                | Reduce data, lower iterations, or raise the timeout.                                                                                           |
| HTTP 401 / 403                                | Missing token, or a foreign `Origin`/`Host` header  | Send `Authorization: Bearer <token>`; add the origin to `D3MCP_HTTP_ALLOWED_ORIGINS`; connect via 127.0.0.1/localhost.                         |
| `Refusing to bind HTTP transport`             | Non-loopback host without a token                   | Set `D3MCP_HTTP_TOKEN`.                                                                                                                        |
| Visual test fails after an intended change    | Baseline is out of date                             | Inspect `*-diff.png`, then run `npm run test:visual:update`.                                                                                   |
| TLS warning during `audit:d3:check`           | `NODE_TLS_REJECT_UNAUTHORIZED=0` set in your shell  | See [security.md](security.md#environment-note).                                                                                               |

Logs: stderr JSON lines (`{"ts","level","msg",...}`). Set `D3MCP_LOG_LEVEL=debug` for more detail.
