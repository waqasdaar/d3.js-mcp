# Security

All inputs (data, prompts, specs, SVG) are treated as untrusted.

| Threat                        | Control                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Test                                                                                                                       |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Code execution                | No `eval`, `new Function` or dynamic import of user input (ESLint `no-eval`, `no-implied-eval`, `no-new-func`). Composition is a whitelist of named operations; field accessors are plain property names.                                                                                                                                                                                                                                                                                                            | `tests/security/security.test.ts` → "composition never evaluates code"                                                     |
| Shell / network access        | No tool runs shell commands. d3-fetch is unsupported; no URL inputs are accepted. Chromium runs offline and aborts every request.                                                                                                                                                                                                                                                                                                                                                                                    | integration tests; `src/export/browser.ts`                                                                                 |
| XSS in artifacts              | Text is inserted via D3 `.text()` or `escapeHtml`; JSON in `<script type="application/json">` uses `jsonForScript`. HTML has a CSP with `default-src 'none'` and SHA-256-pinned inline scripts.                                                                                                                                                                                                                                                                                                                      | "malicious labels are escaped", integration scenario 9, Playwright                                                         |
| Malicious SVG (user-supplied) | `validateSvg` rejects `<script>`, `foreignObject`, `iframe`, `image`, `use`, animation elements, `on*` handlers, external `href`/`src`, `javascript:`/`vbscript:`/`data:text/html`, external `url()`, CSS `@import`, DOCTYPE/ENTITY (XXE). SVG is parsed, never executed.                                                                                                                                                                                                                                            | "user-supplied SVG validation" (7 cases)                                                                                   |
| Custom topology icons         | Path icons: `d` may only contain path commands and numbers; colors must be hex, rgb(), hsl() or named; transforms are limited to matrix/translate/scale/rotate/skew. DOCTYPE/ENTITY is rejected; scripts, handlers, links, `image`/`use`/`foreignObject`/`style`, and `url()` paints are dropped with warnings. Only regular files up to `D3MCP_MAX_FILE_BYTES` are read. URLs are rejected, never fetched.                                                                                                                                                                                                                                                                   | `tests/unit/formats.test.ts` → "blocks paths outside…", integration scenario 15                                            |
| Spreadsheet / YAML parsing    | SheetJS CE 0.20.3 (vendored from the official CDN; npm `xlsx` 0.18.5 has CVE-2023-30533 and CVE-2024-22363). Read with `bookVBA:false`, `cellFormula:false`, and a row cap via `sheetRows`. Header names go through the prototype-pollution check. YAML uses the core schema (no custom tags), `maxAliasCount: 100` and unique keys.                                                                                                                                                                                 | "YAML is parsed safely…", "rejects prototype-pollution header names in sheets"                                             |
| Prototype pollution           | Field names `__proto__`, `prototype`, `constructor` are rejected.                                                                                                                                                                                                                                                                                                                                                                                                                                                    | "rejects prototype-pollution field names"                                                                                  |
| Linked dashboards             | Joined field names are checked against the forbidden keys. Linked records are embedded as `application/json` via `jsonForScript`, which escapes `</script>`. The detail panel is built with `textContent`, never `innerHTML`. Joins are capped by `D3MCP_MAX_ROWS` (N:M explosions are refused), and at most 500 rows per source are embedded. Elicitation only offers server-generated options; answers outside them are ignored.                                                                                   | `tests/unit/link.test.ts` → "embeds linked records as inert JSON…", "refuses row explosions…"; integration scenarios 24–26 |
| Path traversal                | IDs must match `^[A-Za-z0-9_-]{1,64}$`; every path is resolved and must stay inside the artifact root; file names are whitelisted.                                                                                                                                                                                                                                                                                                                                                                                   | "rejects path traversal in ids", integration scenario 9                                                                    |
| Resource exhaustion           | Limits on rows, bytes (text and structured), columns, cell length, hierarchy nodes, geo features, SVG marks, force nodes/links, composition result size, browser timeouts.                                                                                                                                                                                                                                                                                                                                           | data and integration tests (scenario 10)                                                                                   |
| Data leakage in logs          | Logs go to stderr and contain tool name, code, timing and error message only — never data values.                                                                                                                                                                                                                                                                                                                                                                                                                    | `src/server/util.ts`                                                                                                       |
| Stale data on disk            | Artifacts and datasets older than `D3MCP_ARTIFACT_TTL_HOURS` are deleted on start and hourly.                                                                                                                                                                                                                                                                                                                                                                                                                        | `ArtifactStore.cleanup`                                                                                                    |

## Remote mode (Streamable HTTP)

- Binds to `127.0.0.1` by default. Startup is **refused** for a non-loopback `D3MCP_HTTP_HOST` unless `D3MCP_HTTP_TOKEN` is set.
- With a token, every request needs `Authorization: Bearer <token>` (constant-time comparison). The token is never logged.
- `Host` and `Origin` headers are checked against the bound address and `D3MCP_HTTP_ALLOWED_ORIGINS` (DNS-rebinding protection), both by the server and by the SDK transport.
- There are limits on request body size (2 × `D3MCP_MAX_INPUT_BYTES` + 1 MB), session count (100), header and request time.
- The first request must be `initialize`. Unknown session IDs get 404 and malformed JSON gets 400.
- There is no built-in TLS; terminate TLS at a reverse proxy.

All of these are covered by `tests/integration/http.test.ts`.

## Rendering isolation

D3 rendering runs in `worker_threads`. A render exceeding `D3MCP_RENDER_TIMEOUT_MS` is terminated, so a pathological spec cannot hang the server. Tested in `tests/unit/pool.test.ts`.

## Environment note

During verification the shell had `NODE_TLS_REJECT_UNAUTHORIZED=0` set. **This project does not set it.** It disables TLS certificate checks for every Node process in that shell, including `npm` and the `audit:d3:check` fetch. Unset it unless a corporate proxy requires it, and prefer `NODE_EXTRA_CA_CERTS=/path/to/corp-ca.pem`.
